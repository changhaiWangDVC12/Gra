一、一维：位置、切片、负号

   v = np.array([10, 20, 30, 40, 50, 60])      六个格子，编号 0…5

   v[0]    = 10      下标从 0 开始，v[2] 是第三个不是第二个
   v[-1]   = 60      负数从尾巴数：-1 最后一个，-2 倒数第二个
   v[1:4]  = [20 30 40]     含头不含尾：取 1、2、3，长度 = 4-1 = 3
   v[:3]   = [10 20 30]     省略左端 = 从 0 开始
   v[3:]   = [40 50 60]     省略右端 = 取到结尾
   v[::2]  = [10 30 50]     步长 2，每两个取一个
   v[::-1] = [60 50 40 30 20 10]   步长 -1，整条倒过来

  切片三个位置是「起点 : 终点 : 步长」，都能省。轨迹代码里最常用的是 pos[-1]（最后一帧），因为你通常不知道总帧数。

二、二维：逗号是最重要的一个符号（这一节是全篇重点）

   p = [[ 0, 0],        shape (5, 2)：5 帧 × (x, y)
        [12, 0],
        [24, 0],
        [36, 0],
        [48, 0]]

   p[2]     = [24  0]              逗号之前是行 → 整行 = 第 2 帧的位置向量
   p[2, 0]  = 24                   第 2 帧的 x（行在前、列在后）
   p[2, 1]  = 0                    第 2 帧的 y
   p[:, 0]  = [ 0 12 24 36 48]     冒号在行位 = 所有帧的第 0 列 = 整条 x 序列
   p[:, 1]  = [0 0 0 0 0]          整条 y 序列
   p[1:3,:] = [[12 0], [24 0]]     第 1、2 帧（含头不含尾）

  四条口诀：
    p[i, j]              取一个数            形状 ()
    p[i]  = p[i, :]      第 i 行（一整帧）    形状 (2,)
    p[:, j]              第 j 列（所有帧同一量）形状 (100,)
    p[i0:i1, j0:j1]      一块长方形子表        形状 (行数, 列数)

  这就是练习 1 里「帧在前、状态在后」的全部价值：列的含义固定（第 0 列 x、第 1 列 y），所以 p[:, 0] 一句话就是整条 x 序列，不用循环。

  一个必须知道的坑——降维：

    p[:, 0].shape   = (5,)      冒号把那一维压掉了
    p[:, 0:1].shape = (5, 1)    写成切片就保住二维（列向量）

  数值一样、形状不同。以后做广播时差一维就会算错，形状对不上先回来查这里。

三、花式索引：方括号里放「名单」

   p[[0, 2, 4]]      = [[0 0], [24 0], [48 0]]        取第 0、2、4 帧
   p[[3, 0]]         = [[36 0], [0 0]]                能换序
   p[[0, 0, 0]]      = 三个第 0 帧                      能重复
   p[[0, 1], [0, 1]] = [0 0]                          逐对取：(0,0) 和 (1,1)

  记住判据：方括号里是冒号（切片）取连续一段；是列表/数组（花式）按名单取，名单顺序就是结果顺序。换序和重复是切片做不到的。

  注意 p[[0,1],[0,1]] 是「两个名单一一配对」，不是所有组合；要组合得写 p[[0,1]][:, [0,1]]。

四、视图 vs 拷贝：不报错但最危险的一节

   a = np.array([[0,0],[12,0],[24,0],[36,0],[48,0]])
   view  = a[:, 0]      切片 → 视图，和 a 共用同一块内存
   fancy = a[[0, 2]]    花式 → 新数组，数据被复制了

   np.shares_memory(a, a[:, 0])   = True
   np.shares_memory(a, a[[0, 2]]) = False

   view[:] = -1  之后，a 变成全是 -1 的行 —— 原数组被改了。

  一句话判据：切片看、花式抄。只读不要紧，一写就先问自己「我写的是不是原数组」。要保命一律加 .copy()：

   c = b[:, 0].copy()
   c[:] = 999        b 保持原样

  为什么 Python 的 list 没这毛病？list 切片是复制。NumPy 为了省内存（航拍数据几百 MB）故意做成视图——这是从 list 迁到 NumPy 最容易踩的一脚，而且它不报错，只是数字悄悄变了。

五、布尔掩码：先问条件，再去取

   d = np.array([60.10, 52.50, 45.00, 37.50, 30.50])   每帧两车距离
   mask = d < 45     = [False False False True True]   和 d 等长的一串 True/False
   d[mask]           = [37.5 30.5]      只留 True 的位置
   d[(d>35)&(d<55)]  = [52.5 45. 37.5]  两个条件各加括号，用 & 不用 and
   d[~(d<45)]        = [60.1 52.5 45.]  ~ 是取反
   mask.sum() = 2    True 计 1，sum 就是「多少个满足」
   mask.mean() = 0.4 满足条件的比例
   np.where(d<45)    = (array([3, 4]),) 满足条件的下标

  长度必须一致（不等长报 boolean index did not match）；忘了加括号会报 The truth value of an array with more than one element is ambiguous —— 看到这个报错，九成是括号。

  这一招就是课题里的主力：以后「哪些时刻距离小于阈值」「哪些格子风险超过 0.2」都靠它。risk[risk > 0.2] 取出来的是拍平的一维数组。

六、同一套索引用在风险场上（5×5 小网格，行 = y 方向第几格，列 = x 方向第几格）

   risk[2,2]=0.45（自车） risk[1,2]=1.00（正前方最危险） risk[1,3]=0.30 risk[3,2]=0.10

   risk[1]          = [0. 0. 1. 0.3 0.]       整行：同一 y 上沿 x 扫一遍
   risk[:, 2]       = [0. 1. 0.45 0.1 0.]     整列：同一 x 上沿 y 扫一遍
   risk[1, :3]      = [0. 0. 1.]              第 1 行前 3 格
   risk[risk > 0.2] = [1. 0.3 0.45]           超阈值的所有格子
   np.argmax(risk)  = 7                       ← 拍平后的序号，不是行列！
   np.unravel_index(7, (5,5)) = (1, 2)        行列坐标（最危险那格）

  np.argmax 给的是序号，必须用 np.unravel_index 换成行列。以后查「哪个位置风险最高、离自车多远」非会不可，否则你手里只有一个 7，完全不知道指哪儿。

七、六种报错原文（看过一遍，以后一眼认得）

   v[100]（长度 3）  IndexError: index 100 is out of bounds for axis 0 with size 3
                     ——它会告诉你哪一维（axis 0）和该维多大
   v[1.0]            IndexError: only integers, slices (:), ... are valid indices
                     ——下标必须是整数，长度不能当索引用
   p[0,1,2]（二维）  IndexError: too many indices for array: array is 2-dimensional, but 3 were indexed
   arr[np.array([True,False])]（arr 长 3）
                     IndexError: boolean index did not match ... size of axis is 3 but size of corresponding boolean axis is 2
   [[0,0],[1,1]][:,0] TypeError: list indices must be integers or slices, not tuple
                     ——那是 Python list 不是 NumPy 数组，嵌套 list 只能 lst[i][j]
   v[v>10 & v<30]    ValueError: The truth value of an array with more than one element is ambiguous
                     ——少括号

  另有两条不报错、但更要命的：切片视图改到了原数组（第四节）；p[i][j] 与 p[i, j] 对二维结果相同但前者慢、且对花式索引会给出完全不同的结果 —— 统一写 p[i, j]。
